Web Scraping Task

Project Overview

This project demonstrates an automated web scraping pipeline using Python.

Technologies Used

- Python
- BeautifulSoup
- Pandas

Project Files

- scraper.ipynb – Web scraping implementation.
- output.csv – Scraped data output.
- requirements.txt – Required Python libraries.

Installation

Install the required libraries:

pip install -r requirements.txt

Output

The scraped data is stored in CSV format for further analysis.
